**任务卡规格**（14px 标题 / 8px 间距）：

```
┌───────────────────────────────┐
│ [P0]  支付网关对接        ⋮   │  ← 优先级标签(左) + 标题 + 三-dot
│ 描述摘要最多两行…              │  ← --text-3 12px
│ ▸ bash: npm test          45m │  ← 活跃任务：当前动作一行（mono 11px）
│ ● 执行中   #10   2h 前         │  ← 状态徽章 + 任务号 + 创建时间
└───────────────────────────────┘
```

- 排序：列内按 `优先级 → 创建时间`；被抢占的任务带橙色 `⏸ 被抢占` 角标。
- 待回答列：卡片高亮琥珀边框 + `⏳ 3 个问题` 提示，点击直达任务详情问答区。
- **阻塞列**：卡片高亮红色边框（亮红脉冲状态点）+ `⛔ N 个决策项` 提示，点击直达任务详情的阻塞决策卡；阻塞不占并发槽，侧栏/顶栏有红色角标提醒。
- 三-dot 菜单：编辑优先级 / 重命名 / 查看 / 取消（硬确认）/ 删除（done/failed/cancelled 后）。
- 列头计数实时刷新；列间移动用 FLIP 动画。
- 看板设置弹层：本板默认工作目录模式（独立/共享）、是否允许本板任务被抢占。

### P3-x · 阻塞决策卡（任务处于 `blocked` 时，置顶于所有 Tab 之上，红色左边条）

```
┌────────────────────────────────────────────────────────────────────────┐
│ ⛔ 任务已暂停，等待你的决策                              已等待 32m     │
│  决策问题: 消息队列选型 — 本地环境无法安装 RabbitMQ，两条路收益差异大，        │
│           且影响验收标准第 3 条，我无法替你拍板。                             │
│ ── 背景与上下文（agent 自动陈述）──────────────────────────────┐          │
│  · 现状: 计划步骤 3 需要异步通知；原计划用 RabbitMQ (work/plan.json#s3)  │
│  · 已验证: 本机 docker 拉取 rabbitmq 镜像 3 次超时(网络不稳定)，见留言板      │
│  · 影响: 选 A 需改验收标准第 3 条; 选 B 延迟消息需自实现, 工作量 +2h          │
│  · 相关文件: src/notify/index.ts (节选) / work/plan.json / 留言板 #104-117  │
│ ┌─────────────────────────────────────────────────────────────┐        │

│ └─────────────────────────────────────────────────────────────┘        │

│  (●) A. 改用 Redis 队列 + 本机 redis-cli 验证 (agent 推荐: 本机已装 Redis,   │
│       无需改验收标准, +30m)                                              │
│  ( ) B. 保持 RabbitMQ, 我用 docker 离线镜像方式提供                        │
│  ( ) C. 其他: [________________________]                                │
│                                              [ 提交决策 → 任务恢复执行 ]   │
└────────────────────────────────────────────────────────────────────────┘
```

- 触发方式：执行中 agent 写入 `work/block.json` 即停（协议见 05 文档 §4.3）；内容 = 决策问题 + 完整背景上下文（现状/已验证/影响/相关文件节选）+ 2-4 个决策项 + 推荐项与理由。
- **默认无限等待，不自动推进**（必须用户亲自拍板）；设置页可选开启超时策略（如超时 N 小时后按推荐项自动继续，默认关）。
- 用户提交后：决策与理由写入留言板（系统条），session resume 后 agent 从断点继续；该卡折叠为历史记录（同一任务可多次阻塞，历史全部保留）。

### P3-a · 资产 Tab
- 列表式（非网格）：每行 = 类型图标（文件/链接/摘要/截图）+ 名称 + 来源阶段徽章（打磨/执行）+ 大小/时间
- 点名称 → 右侧抽屉预览（markdown 渲染 / 图片 / 外链新窗口打开）
- 头部一行"压缩摘要"：智能体对该资产的 1-2 句结论（R4 handoff 原则：30 秒可读清）
- 支持导出（zip 下载全部资产）

### P3-b · 留言板 Tab（全量活动流，核心）
```
┌────────────────────────────────────────────────────────────────┐
│ 筛选 [全部▾] [仅工具] [仅回复]   ⏸ 自动滚动   字号 [A- A A+]  ⤓导出 │

│ 10:02:11  思考 · 正在评估幂等表设计 (42 行, 可展开)                 │

│            └ 142 行 (展开查看)                                    │
│ 10:03:05  ▸ 工具  bash  npm test -- gateway                     │
│            └ 2m31s · 128 passed · 0 failed (退出码 0)             │
│ 10:05:12  ▸ 工具  edit  src/pay/gateway.ts  (+84 −12)            │
│ 10:07:40  回复                                                 │
│   │ 适配层已完成，重试装饰器采用指数退避…（引用块样式，可折叠长文）     │
│ 10:07:55  系统  ── 阶段切换: 执行 → 测试验收 ──                     │

```
- 每条 = 时间 + 类型 + 摘要行；`思考` 默认压缩为一行（可展开全文）；工具条目可展开参数(JSON)与输出(mono, --bg-inset 块)
- 阶段切换/重试/抢占/恢复 用**系统分隔条**（居中细线 + 标签），流不被淹没
- 实时追加、自动滚动到底（用户上滚即暂停跟随，底部出现"回到最新 ↓"浮标）
- 数据即 pi session 事件流的投影（05 文档 §4）
