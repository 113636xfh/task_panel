**任务卡规格**（14px 标题 / 8px 间距）：

```
┌───────────────────────────────┐
│ [P0]  支付网关对接        ⋮   │  ← 优先级标签(左) + 标题 + 三-dot
│ 描述摘要最多两行…              │  ← --text-3 12px

│ ● 执行中   #10   2h 前         │  ← 状态徽章 + 任务号 + 创建时间
└───────────────────────────────┘
```

- 排序：列内按 `优先级 → 创建时间`；被抢占的任务带橙色 `⏸ 被抢占` 角标。
- 待回答列：卡片高亮琥珀边框 + `⏳ 3 个问题` 提示，点击直达任务详情问答区。
- **阻塞列**：卡片高亮红色边框（亮红脉冲状态点）+ `⛔ N 个决策项` 提示，点击直达任务详情的阻塞决策卡；阻塞不占并发槽，侧栏/顶栏有红色角标提醒。
- 三-dot 菜单：编辑优先级 / 重命名 / 查看 / 取消（硬确认）/ 删除（done/failed/cancelled 后）。
- 列头计数实时刷新；列间移动用 FLIP 动画。
- 看板设置弹层：本板默认工作目录模式（独立/共享）、是否允许本板任务被抢占。

- 触发方式：执行中 agent 写入 `work/block.json` 即停（协议见 05 文档 §4.3）；内容 = 决策问题 + 完整背景上下文（现状/已验证/影响/相关文件节选）+ 2-4 个决策项 + 推荐项与理由。
- **默认无限等待，不自动推进**（必须用户亲自拍板）；设置页可选开启超时策略（如超时 N 小时后按推荐项自动继续，默认关）。
- 用户提交后：决策与理由写入留言板（系统条），session resume 后 agent 从断点继续；该卡折叠为历史记录（同一任务可多次阻塞，历史全部保留）。

### P3-a · 资产 Tab
- 列表式（非网格）：每行 = 类型图标（文件/链接/摘要/截图）+ 名称 + 来源阶段徽章（打磨/执行）+ 大小/时间
- 点名称 → 右侧抽屉预览（markdown 渲染 / 图片 / 外链新窗口打开）
- 头部一行"压缩摘要"：智能体对该资产的 1-2 句结论（R4 handoff 原则：30 秒可读清）
- 支持导出（zip 下载全部资产）

- **用户留言**：accent 左边条 + 「你」标签，与 agent 内容明确区分；发送后若任务活跃走 pi `steer`（当前工具轮结束后、下次 LLM 调用前注入），非活跃则入队待下次启动/恢复时合入；发送失败/无活跃进程时标灰提示

- 实时追加、自动滚动到底（用户上滚即暂停跟随，底部出现"回到最新 ↓"浮标）
- 数据即 pi session 事件流的投影（05 文档 §4）

## P4 · Skills & 扩展 `/skills`（三层继承，分框展示）

> 继承链：① 全部任务**默认继承全局**；② 同项目（同工作目录）任务**继承同目录下其他任务装的技能**（目录内共享 `.pi/`）；③ 用户可**手动给单个任务增加**。任务生效集 = ① ∪ ② ∪ ③。

```
┌────────────────────────────────────────────────────────────────────────────────┐
│  Skills & 扩展                              [刷新扫描] [从磁盘安装…]            │
│  [ 技能 ]  [ 扩展 ]        上下文: (●)全部 ( )任务 #10 支付网关 ( )项目 后端重构  │
├────────────────────────────────────────────────────────────────────────────────┤
│ ┌─ ① 全局继承（所有任务默认生效，只读）─────────────────────────────┐ │
│ │ 来源 ~/.pi/agent/skills、~/.agents/skills（不可删；可复制给任务/项目）  │ │
│ │ ● svg-diagram-authoring  绘制/编辑流程图 SVG…            [查看] [复制→] │ │
│ │ ● babysit              保持 PR 合并就绪…                  [查看] [复制→] │ │
│ └────────────────────────────────────────────────────────────────────┘ │
│ ┌─ ② 项目层继承（同目录任务互相继承）────────────────────────────────────┐ │
│ │ 后端重构 (D:/e5/backend) → .pi/skills                                  │ │
│ │   ● my-skill   我的技能…  来源: 任务 #10 添加 → 本目录 12 任务共享   [查看] │ │
│ │ 前端 (D:/e5/frontend) → .pi/skills                                     │ │
│ │   （空状态: 该目录暂无项目层技能）                                        │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ ┌─ ③ 任务级手动添加（仅对该任务生效）──────────────────────────────┐ │
│ │ 上下文选「任务 #10」时: 列表变勾选模式 + [将选中项添加到此任务]              │ │
│ │  已添加: my-skill(复制自全局) / my-ext(本地新增)        [移除] [查看]     │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────────────┘
```

- ① 全局：pi 默认行为，永远生效；UI 只读，仅提供「查看 SKILL.md 原文 / 打开目录 / 复制到任务或项目目录」
- ② 项目层：共享工作目录模式下的 `.pi/` 天然共享——同目录任一任务添加后，同目录所有任务自动继承；卡片标注「来源: 任务 #N 添加」
- ③ 手动添加：[将选中项添加到此任务] 复制到该任务 workspace 的 `.pi/skills|extensions/`（仅该任务生效）；可移除（只删副本，不动来源）
- 任务详情页顶部有「生效技能 5 全局 + 1 项目 + 2 任务级」摘要条，点击跳本页并选中该任务上下文
