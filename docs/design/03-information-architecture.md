# 03 · 信息架构

## 1. 页面地图

```
Task Panel
├─ /boards                     看板列表（默认落地页）
├─ /boards/:id                 看板详情（七列任务板 + 任务卡）
├─ /boards/:id/tasks/:taskId   任务详情（计划/分支问答/资产/留言板/验收）
├─ /skills                     Skills & Extensions 总览（全局 vs 项目层）
└─ /settings                   运行时与模型设置（并发、超时、重试、模型）
```

## 2. 全局框架（所有页面共用）

```
┌────────────────────────────────────────────────────────────────────┐
│ ▉ 侧栏 232px        │ 主区                                          │
│  LOGO "Task Panel"  │  ┌──────────────────────────────────────────┐│
│                     │  │ 顶栏 48px：页标题 ···  [⌘K 搜索] [◐] [●2/2] ││
│  ▸ 看板             │  └──────────────────────────────────────────┘│
│  ▸ Skills & 扩展    │                                              │
│  ▸ 设置             │        内容区（max-w 1440 居中）              │
│                     │                                              │
│ ─────────────────  │                                              │
│  运行状态卡          │                                              │
│  槽位 2/2  ● ●      │                                              │
│  排队 3 · 阻塞 1 · 待确认 1  │                                              │
└────────────────────────────────────────────────────────────────────┘
```

- 侧栏底部**运行状态卡**常驻：并发槽位占用（● 占用 / ○ 空闲）、排队数、阻塞数（红）、待确认数 —— 一眼掌握全局（Manager Surface 原则）。
- 顶栏右侧 `●2/2` = 槽位速览；有任务等待输入/阻塞/待确认时，侧栏对应导航项出现**琥珀/红/黄色角标**（阻塞=红色，最高醒目度）。
- ⌘K 命令面板：搜任务 / 跳页面 / 常用动作（新建任务、切主题、暂停调度）。

## 3. 导航规则

- 看板列表 → 看板详情：面包屑 `看板 / <名称>`
- 任务卡点击 → 任务详情；详情页顶部返回看板
- Skills 页从任务详情"添加技能/扩展"进入，携带 `?task=<id>` 参数，返回后自动勾选

## 4. 实时性

- 所有列表/卡片状态、运行状态卡经 WebSocket 推送（事件见 05 文档 §6）
- 日志流断线自动重连 + 补拉（按事件序号）
